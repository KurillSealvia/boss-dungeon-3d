# Подземелье боссов 3D

Роглайк-арена на Python и [Ursina](https://www.ursinaengine.org/): 5 этажей, 5 боссов в случайном порядке,
выбор стиля боя в начале забега и реликвии между этажами. Смерть завершает забег.

## Что в игре

- **3D-арена** с камерой от третьего лица, от первого лица и сверху (переключение — `V`).
- **5 боссов** со своим набором телеграфируемых атак, ближними ударами и снарядами:
  «Близнецы-стражи», «Костяной шутник», «Клинок-вихрь», «Король пепла», «Рыцарь Бездны».
- **4 стиля боя**, выбираются перед забегом: Стрелок, Шквал, Дробовик, Клинок.
- **Реликвии**: после каждого этажа выбор одной из трёх (урон, темп стрельбы, HP, щит, вампиризм и т. д.).
- **HUD с иконками способностей**: видно откат и свечение готовности, не отводя взгляд от босса.
- **Настройки**: чувствительность мыши, FOV, вид по умолчанию — сохраняются в `settings.json`.
- **Пауза** (`Esc`) с доступом к настройкам и выходом в меню.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` | движение |
| мышь | обзор (в видах от 1-го и 3-го лица) |
| `ЛКМ` | атака (зависит от стиля) |
| `Space` | рывок с неуязвимостью |
| `Q` | взрыв вокруг героя |
| `E` | щит |
| `V` | сменить вид камеры |
| `1`–`4` | выбор стиля / реликвии |
| `Esc` | меню, пауза |
| `Enter` | новый забег после смерти |

## Запуск

Нужен Python 3.10+ и Ursina:

```bash
pip install ursina
python boss_dungeon_3d.py
```

Или запустить `play.bat` (использует Python из `%LOCALAPPDATA%\Programs\Python\Python312`).

Проверка без окна игры (делает скриншоты `test_*.png`):

```bash
python boss_dungeon_3d.py --test
```

## Файлы

| Файл | Описание |
|---|---|
| `boss_dungeon_3d.py` | вся игра: бой, боссы, стили, HUD, меню, автотест |
| `ABILITIES.md` | стартовые характеристики и способности героя |
| `play.bat` | запуск игры |
| `dungeon.html`, `index.html` | старые веб-версии / прототипы |
| `settings.json` | локальные настройки (не входит в репозиторий) |

## Идеи и баланс

Значения героя заданы в словаре `P`, стили — в `STYLES`, боссы и их атаки — в `BOSS_AI`
в начале `boss_dungeon_3d.py`. Документ `ABILITIES.md` описывает базовый набор способностей.
